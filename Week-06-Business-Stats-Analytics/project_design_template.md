# Project Name
  The Flavor Lab
  
# Project Scope
  An interactive app that tells you which ingredients go well together. Pick ingredients to see recipe suggestions and flavor matches. 
  
# Key Features
  ## For MVP:
  Flavor Network/Node Graph outputing compatible flavor pairings
  Recipes
  
# Frameworks/Libraries
  Gephi - to make the graph
  SQLite/MongoDB - to connect dataset
  Flask
  React, Tailwind CSS, shadcn
  
# Audience (Who is this project for?)
  People who are looking for new recipes and food ideas
  
# Workflow Diagram (use any software you like to generate one)
  Figjam in Figma

# List of Tasks
  Figure out database(s)
  Figure out how to manipulate the database for graph generation
  Connect to backend
  Generate graph
  retreive relevant recipes based on selections on graph generation
  UI
  Conect frontend and backend
